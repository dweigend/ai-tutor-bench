# AI Tutor Bench

AI Tutor Bench is the planned evaluation toolkit for AI Tutor. It will use versioned scenarios and rubrics to check whether a tutor gives useful hints, responds to mistakes, and avoids giving away solutions. The benchmark measures tutor behavior. Learning gains require a separate study.

This repository currently contains this overview.
